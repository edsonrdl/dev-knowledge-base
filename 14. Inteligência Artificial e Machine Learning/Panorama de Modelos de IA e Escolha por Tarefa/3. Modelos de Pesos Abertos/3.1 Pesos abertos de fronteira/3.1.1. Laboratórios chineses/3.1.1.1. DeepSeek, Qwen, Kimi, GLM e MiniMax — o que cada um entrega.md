## Visão geral

Os laboratórios chineses lideram hoje os **modelos de pesos abertos de fronteira**. São grandes modelos Mixture-of-Experts (MoE), em que só uma fração dos parâmetros é ativada por token, o que reduz o custo de inferência.

> **Analogia:** uma biblioteca com centenas de especialistas, mas só uns poucos atendem cada pergunta. A biblioteca é enorme, o atendimento é rápido.

## Quando usar

```
 Código agêntico barato e em escala        ──► DeepSeek V4.x Flash / MiniMax
 Raciocínio e agentes mais difíceis (aberto)──► Kimi K3.x
 Código privado em GPU própria (24 GB)     ──► Qwen3.8-27B
 Contexto longo com bom custo              ──► GLM-5.x
```

## Exemplo prático

Uma empresa processa milhões de tickets por mês e não quer dados saindo da infraestrutura. Hospeda o Qwen3.8-27B (Apache 2.0) em GPUs próprias para classificar e resumir, e reserva um modelo de fronteira pago apenas para casos que o pequeno não resolve.

## Erros comuns e armadilhas

- Comparar **preço de API de terceiros** (Together, OpenRouter) com o preço oficial: mudam por provedor.
- Ignorar a **licença**: "aberto" não significa "livre para qualquer uso comercial".
- Esquecer **conformidade e governança**: dados enviados à API do laboratório de origem podem ter implicações regulatórias; hospedar os pesos você mesmo é outra situação.
- Achar que o parâmetro total diz o custo; o que pesa é o número de parâmetros **ativos** e o hardware necessário.
