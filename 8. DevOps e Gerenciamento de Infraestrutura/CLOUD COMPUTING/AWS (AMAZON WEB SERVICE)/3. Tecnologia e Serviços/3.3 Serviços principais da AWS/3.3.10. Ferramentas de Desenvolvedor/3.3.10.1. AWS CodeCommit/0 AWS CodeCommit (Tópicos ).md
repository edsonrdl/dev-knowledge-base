# 📚 Guia de Estudos: AWS CodeCommit
#tag #aws #cloud #devtools #codecommit #git #cicd #repositorio

> [!info] Visão Geral
> O AWS CodeCommit é o serviço gerenciado de repositórios Git da AWS: repositórios privados na sua conta e região, acesso por IAM, criptografia com KMS, pull requests com approval rules, eventos no EventBridge e integração nativa com CodePipeline e CodeBuild. Este guia cobre fundamentos (incluindo o status de disponibilidade do serviço), repositórios e acesso, colaboração e qualidade, automação e eventos, segurança e governança, e operação, custos e migração.
