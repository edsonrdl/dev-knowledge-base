# 📚 Guia de Estudos: Amazon Macie
#tag #aws #cloud #seguranca #macie #s3 #privacidade #lgpd #dlp

> [!info] Visão Geral
> O Amazon Macie é o serviço gerenciado de segurança e privacidade de dados da AWS: descobre e classifica dados sensíveis (PII, financeiros, credenciais e identificadores próprios) em buckets S3 e avalia a postura de segurança desses buckets. Este guia cobre fundamentos, descoberta automatizada e jobs, identificadores e findings, multi-conta e integrações (Organizations, Security Hub, EventBridge), segurança e privacidade do próprio Macie e operação (custos, quotas, runbooks).
