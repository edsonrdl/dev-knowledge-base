# 📚 Guia de Estudos: Amazon Lightsail
#tag #aws #cloud #computacao #lightsail #vps

> [!info] Visão Geral
> O Amazon Lightsail é a forma simplificada da AWS de rodar servidores, containers, bancos, armazenamento e rede com planos de preço fixo. Este guia cobre os conceitos e planos, as instâncias (IP estático, firewall, snapshots), os container services, dados (discos, buckets e bancos gerenciados), a rede (load balancer, CDN, DNS, TLS) e a integração e evolução (VPC peering, exportação para EC2, custos e limites).
