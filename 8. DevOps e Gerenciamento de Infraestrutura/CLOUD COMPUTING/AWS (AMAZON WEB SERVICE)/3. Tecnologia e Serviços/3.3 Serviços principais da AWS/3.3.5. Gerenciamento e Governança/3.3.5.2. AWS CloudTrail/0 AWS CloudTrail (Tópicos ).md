# 📚 Guia de Estudos: AWS CloudTrail
#tag #aws #cloud #auditoria #cloudtrail #seguranca #governanca

> [!info] Visão Geral
> O AWS CloudTrail registra as chamadas de API e as ações feitas na conta AWS, respondendo a quem fez o quê, quando, de onde e com que resultado. Este guia cobre os fundamentos e o Event history, as trilhas (multirregião, organization trail, S3, validação, KMS), os tipos de evento (management, data, Insights), a análise (Athena e CloudTrail Lake), a segurança (detecção, forense, playbooks) e a operação (custos, IAM, retenção e conformidade).
