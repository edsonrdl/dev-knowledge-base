# 📚 Guia de Estudos: AWS CloudWatch
#tag #aws #cloud #observabilidade #cloudwatch #monitoramento

> [!info] Visão Geral
> O Amazon CloudWatch é o serviço de observabilidade da AWS: coleta métricas, logs e eventos, dispara alarmes e organiza tudo em dashboards e insights. Este guia cobre os fundamentos, as métricas (namespaces, dimensões, EMF, Metric Math), os alarmes (estados, missing data, compostos, anomaly detection), o CloudWatch Logs (retenção, filtros, Insights), a observabilidade avançada (Container Insights, Synthetics, RUM, Application Signals) e a operação (custos, IAM, cross-account).
