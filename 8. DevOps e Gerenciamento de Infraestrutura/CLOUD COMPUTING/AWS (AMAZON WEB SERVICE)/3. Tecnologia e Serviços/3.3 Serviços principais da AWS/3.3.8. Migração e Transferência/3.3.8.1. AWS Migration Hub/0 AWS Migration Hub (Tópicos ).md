# 📚 Guia de Estudos: AWS Migration Hub
#tag #aws #cloud #migracao #migrationhub #discovery #mgn #7rs

> [!info] Visão Geral
> O AWS Migration Hub é o painel central de visibilidade, planejamento e acompanhamento de migrações para a AWS: consolida o status das ferramentas que executam o trabalho (Application Discovery Service, Application Migration Service, Database Migration Service) e apoia a descoberta, a escolha de estratégia (7 Rs), a orquestração de workflows e a refatoração incremental. Este guia cobre fundamentos e Home Region, descoberta e inventário, estratégias e ondas, rastreamento e orquestração, modernização e segurança e operação.
