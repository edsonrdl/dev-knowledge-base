# 📚 Guia de Estudos: IA no desenvolvimento de software
#tag #aws #cloud #ia #amazon-q #kiro #assistentes-de-codigo #testes #cicd #seguranca

> [!info] Visão Geral
> Assistentes de código e agentes de IA (Amazon Q Developer, Kiro e similares) entram em todo o ciclo de vida: geração e refatoração de código, testes, revisão de PRs, CI/CD, diagnóstico de erros e otimização. Este guia cobre fundamentos e modos de uso, rotina de trabalho (prompts, agentes, regras de projeto, MCP, IaC), IA em testes e CI/CD, IA para analisar erros e otimizar (Q no console, CloudWatch, DevOps Guru, Compute Optimizer), segurança e governança (código gerado, segredos, licenças, dependências, permissões de agentes) e adoção responsável (métricas, custos, limites).
