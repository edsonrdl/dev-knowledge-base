- Fontes de terceiros indicam que a AWS está renovando SAP-C02, DVA-C02 e MLA-C01 entre set e dez/2026; o **DVA-C03 está confirmado** na página oficial do guia. Para o **SAA**, não foi encontrada data de substituição oficial; revise a página oficial antes de agendar.

## 5. Como validar um fato antes de estudar
1. Procure o ID de skill no Exam Guide oficial (seção 1).
2. Confirme limites/números na doc do serviço (seção 2) — cotas mudam.
3. Compare com a explicação da comunidade (seção 3); em divergência, vale a doc oficial.
4. Registre a data de verificação neste arquivo (campo `verificado-em`).
